## Hozzájárulás és visszajelzés

A repository tartalma automatikusan generált és publikált tartalom. A repository közvetlen közösségi fejlesztése nem támogatott, ezért Issue vagy Pull Request beküldésére nincs lehetőség.

A repository tartalmával kapcsolatos hibát, észrevételt vagy módosítási javaslatot kérjük, a Nemzeti Adó- és Vámhivatal hivatalos kapcsolatfelvételi felületén jelezze:
[Levélküldés a Nemzeti Adó- és Vámhivatal részére](https://nav.gov.hu/ugyfeliranytu/keressen_minket/levelkuldes?subjectid=92).

A bejelentésben kérjük egyértelműen megjelölni az érintett repository-t, valamint lehetőség szerint az érintett űrlapsablont és annak verzióját.
